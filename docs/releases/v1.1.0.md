# OpSec Audit Tool v1.1.0

Das Enterprise-Grade Release **v1.1.0** des portablen OpSec Audit Tools von **SolidStateNetwork** bringt eine vollständig globalisierte Theme-Architektur, modulare C#-Präsentationsschichten, 10 neue Zero-Admin Core-Checker und verfeinerte UI-Interaktionen.

## Neuerungen und Verbesserungen

- **Zentrales Design-System (`Theme/AppStyles.axaml`)**: Einheitliche Stile für Buttons, Checkboxen, Expander, TabControl, ScrollBars und Custom Controls (`CopyBtn`, `TxtBtn`, `JsonBtn`, `MarkdownBtn`, `HeaderBlockBtn`, `DisclosureBtn`).
- **Umfassender XAML-Cleanup**: Entfernung von über 770 Zeilen redundanter Inline- und Fensterstile aus `MainWindow.axaml` und `OpSecBibleWindow.axaml`.
- **C#-Modularisierung (`ConsoleLogPresenter.cs`)**: Vollständige Kapselung der farbigen Live-Konsolen-Logik (80-ms-Batching, Warteschlange, Auto-Scroll-Tracking, LogLevel-Farbgebung und Dispose-Management) zur Entlastung des Code-Behinds.
- **10 neue Zero-Admin Core-Checker** (insgesamt 58 Checker):
  - Docker/Podman Container-Sicherheit
  - SSH-Client-Konfiguration
  - Display-Server (Wayland/X11) Security
  - Git Security Config & Credentials
  - KI-Tooling & Privacy Leak Detection
  - Encrypted DNS (DoT/DoH) u. v. m.
- **Backup-Service**: Unterstützung für automatisiertes lokales Sichern und Wiederherstellen von Einstellungen und Berichten.
- **Verfeinerte Cyber-Terminal-Ästhetik**: Präzises Neongrün (`#00FF66`) bei aktiven Elementen und Borderline-Overlays, durchgängig abgestimmte Tab-Hintergründe und reaktive Button-Hover.
- **100 % Portable & Zero-Admin**: Keine Administratorrechte erforderlich, vollständiger Offline-Betrieb ohne Telemetrie, alle Daten bleiben lokal am Ausführungsort.
